# DDU Form Page

React single-page application built with Vite.

## Run Locally

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Vite will print a local URL, usually:

```text
http://localhost:5173/
```

Open that URL in your browser. The dev server supports hot module replacement, so code changes are reflected automatically.

## Build And Run In Production

Create a production build:

```bash
npm run build
```

The compiled files will be generated in the `dist` directory.

To preview the production build locally:

```bash
npm run preview
```

Vite will print a local preview URL, usually:

```text
http://localhost:4173/
```

For a real production environment, deploy the contents of the `dist` directory to a static hosting service or web server.
